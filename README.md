# Laravel Blog CMS

A dynamic Blog Management System built using Laravel with CRUD functionality, AJAX category filtering, rich text editor, image uploads, and responsive frontend design.

---

## Features

- Create, Read, Update, Delete (CRUD) Blogs
- Admin Dashboard
- AJAX Category Filtering
- Rich Text Blog Editor
- Image Upload Support
- Responsive UI using Bootstrap
- Blog Detail Page
- Dynamic Categories
- MySQL Database Integration

---

## Technologies Used

- Laravel
- PHP
- MySQL
- Bootstrap 5
- JavaScript
- AJAX
- HTML/CSS
